# Phase C — Progression Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Persist per-level completion, a touch-count medal and a best time, and show all three on the level select and the Results screen.

**Architecture:** The simulation records one new integer (`WinningFrames`) and knows nothing else about progression. Every rule — grading a run against par, merging it into a record, deriving world unlock, formatting a time — is a pure static function in `KeepyUppy.Shell` with no Unity types and no IO. Storage is one JSON blob behind a two-member `ISaveStore`, with `PlayerPrefsSaveStore` the only untested part and `MemorySaveStore` standing in for it in tests. `ShellView` records on the existing win edge and draws the results; it gains no decisions.

**Tech Stack:** Unity 6000.2.6f2, C#, `JsonUtility`, `PlayerPrefs`, NUnit EditMode tests. No new packages.

**Spec:** `docs/superpowers/specs/2026-08-27-progression-save-data-design.md`

```csharp
using System;

namespace KeepyUppy.Shell.Save
{
    /// <summary>
    /// Everything that survives closing the game. One blob, written as JSON into a single
    /// PlayerPrefs key (spec: progression and save data, 3).
    ///
    /// Modelled for JsonUtility under the same constraints LevelData and LevelIndex work
    /// within: a flat array of objects, no nested arrays, no dictionaries.
    ///
    /// Death counts are deliberately absent. GDD 15 wants them displayed and never hidden,
    /// but says nothing about keeping them, and a per-session count is the more useful number
    /// while levels are being tuned.
    /// </summary>
    [Serializable]
    public sealed class SaveData
    {
        /// <summary>Bumped only when the shape changes in a way a reader must handle.</summary>
        public const int CurrentVersion = 1;

        public int version = CurrentVersion;
        public LevelRecord[] levels = new LevelRecord[0];
    }

    /// <summary>
    /// One level's best. Times are FRAMES, not seconds: integers, exactly reproducible, and
    /// it keeps SimClock the only measure of time in the project.
    /// </summary>
    [Serializable]
    public sealed class LevelRecord
    {
        public string id = "";
        public bool cleared;
        public int bestTouches;
        public int bestTimeFrames;

        /// <summary>
        /// The medal earned by the run that set <see cref="bestTouches"/>, graded at win time
        /// when the level's par was in hand. Stored rather than re-derived because par lives
        /// inside each level file, and grading in the menu would mean parsing every level in
        /// the game to draw it. The accepted cost: re-tuning a par does not re-grade records
        /// until the level is played again.
        /// </summary>
        public int medal;
    }

    /// <summary>The touch-count medal (GDD 15). Ordered, so a later tier is a better one.</summary>
    public enum Medal
    {
        None = 0,
        Bronze = 1,
        Silver = 2,
        Gold = 3,
    }
}
```

```csharp
namespace KeepyUppy.Shell.Save
{
    /// <summary>
    /// Every progression rule, as pure functions. No Unity types, no IO, no state — so all of
    /// it is reachable from an EditMode test without a scene, which is the whole reason the
    /// rules are not in ShellView.
    /// </summary>
    public static class SaveModel
    {
        /// <summary>How far over par still earns silver.</summary>
        public const int SilverSlack = 3;

        /// <summary>
        /// The touch-count medal (GDD 15). Three tiers rather than one because the gradient is
        /// the point: GDD 4.2 makes the fewest-touches line the most dangerous line in the
        /// game, and a player who missed gold by one touch needs something to aim at.
        ///
        /// A par of zero or less means UNSET — the normal state while a level is authored,
        /// since par comes from playtest metrics. An unset par can never award gold.
        /// </summary>
        public static Medal Grade(int touches, int parTouches)
        {
            if (parTouches <= 0) return Medal.Bronze;
            if (touches <= parTouches) return Medal.Gold;
            if (touches <= parTouches + SilverSlack) return Medal.Silver;

            return Medal.Bronze;
        }
    }
}
```

```csharp
        /// <summary>The stored record for a level, or null if it has never been cleared.</summary>
        public static LevelRecord RecordFor(SaveData data, string levelId)
        {
            if (data?.levels == null || string.IsNullOrEmpty(levelId)) return null;

            foreach (LevelRecord record in data.levels)
                if (record != null && record.id == levelId) return record;

            return null;
        }

        /// <summary>
        /// Folds a completed run into the save and returns the result.
        ///
        /// Each field takes its own best independently: a slow gold run and a fast bronze run
        /// both leave their mark, and the medal follows bestTouches. A first clear sets both
        /// and flags neither as a new best — there was nothing to beat.
        ///
        /// Never mutates its input: the caller's SaveData is the one already on screen, and a
        /// merge that edited it in place would change what is drawn before anything decided to
        /// keep it. Records for levels no longer in the manifest are copied through rather than
        /// pruned — an unlisted level is a draft (menus spec 1) and may well come back.
        /// </summary>
        public static SaveResult Merge(SaveData data, RunResult run)
        {
            var next = new SaveData { version = SaveData.CurrentVersion };
            LevelRecord existing = RecordFor(data, run.LevelId);

            var updated = new LevelRecord
            {
                id = run.LevelId,
                cleared = true,
                bestTouches = existing != null ? Min(existing.bestTouches, run.Touches) : run.Touches,
                bestTimeFrames = existing != null ? Min(existing.bestTimeFrames, run.TimeFrames) : run.TimeFrames,
            };

            bool newBestTouches = existing != null && run.Touches < existing.bestTouches;
            bool newBestTime = existing != null && run.TimeFrames < existing.bestTimeFrames;

            // The medal describes the best touch run, so it is only re-graded when that run
            // changes - a first clear included.
            updated.medal = existing == null || newBestTouches
                ? (int)Grade(updated.bestTouches, run.ParTouches)
                : existing.medal;

            var levels = new System.Collections.Generic.List<LevelRecord>();
            if (data?.levels != null)
            {
                foreach (LevelRecord record in data.levels)
                {
                    if (record == null || record.id == run.LevelId) continue;

                    levels.Add(new LevelRecord
                    {
                        id = record.id,
                        cleared = record.cleared,
                        bestTouches = record.bestTouches,
                        bestTimeFrames = record.bestTimeFrames,
                        medal = record.medal,
                    });
                }
            }

            levels.Add(updated);
            next.levels = levels.ToArray();

            return new SaveResult(next, updated, newBestTouches, newBestTime);
        }

        static int Min(int a, int b) => a < b ? a : b;
```

```csharp
        /// <summary>
        /// Frames as M:SS.CC. Frames are the stored unit (SimClock is the only measure of time
        /// in this project); this is the only place they become something to read.
        /// </summary>
        public static string FormatTime(int frames)
        {
            if (frames < 0) frames = 0;

            int totalHundredths = frames * 100 / SimClock.Hz;
            int hundredths = totalHundredths % 100;
            int totalSeconds = totalHundredths / 100;
            int seconds = totalSeconds % 60;
            int minutes = totalSeconds / 60;

            return $"{minutes}:{seconds:00}.{hundredths:00}";
        }

        /// <summary>
        /// World 1 is always open; world N opens when every level of world N-1 is cleared
        /// (menus spec 2). Derived, never stored — a stored unlock is a second source of truth
        /// that can disagree with the records it was derived from.
        ///
        /// NOTHING CALLS THIS YET. Gating is deliberately out of scope for phase C (spec 6):
        /// there is one world to gate today. It is written here because this is where a reader
        /// looks for it and because its skipped-level behaviour is worth pinning down while
        /// the rest is fresh. If gating never arrives, deleting this costs nothing.
        /// </summary>
        public static bool WorldUnlocked(LevelIndex index, SaveData data, int worldNumber)
        {
            if (index?.worlds == null) return false;
            if (worldNumber < 1 || worldNumber > index.worlds.Length) return false;
            if (worldNumber == 1) return true;

            LevelWorld previous = index.worlds[worldNumber - 2];
            if (previous?.levels == null) return true;   // nothing to clear, nothing to block

            foreach (string id in previous.levels)
            {
                LevelRecord record = RecordFor(data, id);
                if (record == null || !record.cleared) return false;
            }

            return true;
        }
```

```csharp
using UnityEngine;

namespace KeepyUppy.Shell.Save
{
    /// <summary>
    /// Holds the save in memory and is the only thing that touches an <see cref="ISaveStore"/>.
    /// Loaded once at construction; written on a clear and on a wipe, and nowhere else — a
    /// completed level is the only event that changes persisted state.
    ///
    /// Anything the reader cannot understand — malformed JSON, or a version from the future —
    /// becomes a fresh save rather than an exception. A lost record beats a boot that throws,
    /// and the version field is there so a later schema change can do better than either.
    /// </summary>
    public sealed class SaveService
    {
        readonly ISaveStore _store;

        public SaveData Data { get; private set; }

        /// <summary>
        /// Bumped on every write. The shell redraws only when something visible changed, so it
        /// needs one value that moves when the save does.
        /// </summary>
        public int Generation { get; private set; }

        public SaveService(ISaveStore store)
        {
            _store = store;
            Data = Load(store);
        }

        static SaveData Load(ISaveStore store)
        {
            string json = store?.Read();
            if (string.IsNullOrEmpty(json)) return new SaveData();

            SaveData loaded;
            try
            {
                loaded = JsonUtility.FromJson<SaveData>(json);
            }
            catch (System.Exception e)
            {
                Debug.LogWarning($"[save] unreadable, starting fresh: {e.Message}");
                return new SaveData();
            }

            if (loaded == null) return new SaveData();

            if (loaded.version > SaveData.CurrentVersion)
            {
                Debug.LogWarning($"[save] version {loaded.version} is newer than this build's " +
                                 $"{SaveData.CurrentVersion}; starting fresh");
                return new SaveData();
            }

            loaded.levels ??= new LevelRecord[0];
            return loaded;
        }

        public LevelRecord RecordFor(string levelId) => SaveModel.RecordFor(Data, levelId);

        /// <summary>
        /// Folds a completed run in and writes. Returns the merge result so the caller can draw
        /// whether anything was beaten, which is only knowable here.
        /// </summary>
        public SaveResult RecordClear(RunResult run)
        {
            SaveResult result = SaveModel.Merge(Data, run);
            Data = result.Data;
            Flush();

            return result;
        }

        /// <summary>Dev-only, and only ever reached from a LEVEL_EDITOR-gated call site.</summary>
        public void Wipe()
        {
            Data = new SaveData();
            Flush();
        }

        void Flush()
        {
            Generation++;
            _store?.Write(JsonUtility.ToJson(Data));
        }
    }
}
```
