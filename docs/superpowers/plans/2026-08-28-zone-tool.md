# Zone tool implementation plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Make air zones drawable, movable, resizable and deletable in the in-game level editor, so the only way to change one stops being hand-editing JSON.

**Architecture:** Rect maths goes in a new pure static `ZoneGeometry`; zone state and mutations go on `EditorSession` beside the existing entity operations; `LevelEditorController` contributes only mouse grammar and drawing. Both tested pieces are plain C# with no scene, no camera and no input, matching how every other editor rule in this project is tested.

**Tech Stack:** Unity 6000.2.6f2, C#, NUnit EditMode tests, IMGUI for dev panels, `Unity.InputSystem` for the mouse and keyboard.

**Spec:** `docs/superpowers/specs/2026-08-28-zone-tool-design.md`

## Global Constraints

- **Do not create or edit `.unity`, `.prefab` or `.asset` files.** Everything is constructed in code (CLAUDE.md).
- **`LevelEditor/` must contain no `using UnityEditor;`** anywhere. It is runtime code that is merely dev-only, and must survive into development builds.
- **The `LevelEditor` folder must never be renamed `Editor`.** Unity strips any folder called `Editor` from builds.
- Only `LevelEditorController.cs` is wrapped in `#if LEVEL_EDITOR`. The plain C# classes (`EditorSession`, `GridCursor`, `UndoStack`, `EditorTool`) are ungated so the tests can reach them. **New pure classes are ungated; new IMGUI classes are gated**, matching that split.
- **The editor and the game read the same JSON.** Never a second level format (CLAUDE.md).
- **Run tests with `./test.sh`** from the repo root. Exit code `0` means every test passed. **Unity must not be open** — batch mode takes an exclusive lock on `Library/`, and the run will fail with `HandleProjectAlreadyOpenInAnotherInstance`. If it does, stop and ask for the editor to be closed. Do not retry in a loop and do not delete `Library/`.
- **A task is not done until `./test.sh` passes with 0 compiler warnings.** Check warnings with `grep -c "warning CS" TestResults/test-run.log`.
- Nothing in this plan adds state to the simulation, so the replay-equality determinism test needs no new coverage. If a task finds itself touching `Assets/_Project/Scripts/Sim/`, stop — that is out of scope and a sign the design has drifted.
- Zone rects snap to **whole tiles** (level-editor-spec §3). Entities snap to half-tile; do not copy `SnapHalfTile`.
- Levels are JSON and must keep producing readable diffs: no minifying, stable key order.

**Deliberate deviation from the spec, already agreed:** the spec's file table names `MoveZone` and `ResizeZone`. This plan implements a single `SetZoneRect(id, rect)` instead — the geometry decides whether a given drag is a move or a resize, so two methods would be the same body twice.

```csharp
using KeepyUppy.Sim;
using UnityEngine;

namespace KeepyUppy.LevelEditing
{
    /// <summary>Which corner of a zone rect a drag has hold of.</summary>
    public enum ZoneCorner
    {
        None = 0,
        BottomLeft = 1,
        BottomRight = 2,
        TopLeft = 3,
        TopRight = 4,
    }

    /// <summary>
    /// Rect maths for the zone tool (level-editor-spec 3: zone rects snap to tile).
    ///
    /// Pure statics, no camera and no scene, for the same reason GridCursor is: a backwards
    /// drag and a handle dragged past the far edge are otherwise only findable by clicking.
    ///
    /// Everything routes through <see cref="GridCursor.TileRect"/>, which already normalises
    /// a drag in any direction and clamps it to the room. Because it is inclusive it can
    /// never return a zero-area rect, so the 1x1 minimum falls out rather than being
    /// enforced separately.
    /// </summary>
    public static class ZoneGeometry
    {
        /// <summary>Inclusive tile rect between two tiles, as a world-space Rect.</summary>
        public static Rect Normalise(Vector2Int a, Vector2Int b)
        {
            RectInt tiles = GridCursor.TileRect(a, b);
            return new Rect(tiles.x, tiles.y, tiles.width, tiles.height);
        }

        public static Rect Normalise(Vector2 a, Vector2 b)
            => Normalise(GridCursor.ToTile(a), GridCursor.ToTile(b));

        /// <summary>
        /// The corner handle under a world position, or None. Nearest wins, so a 1x1 zone
        /// whose corners all fall inside the radius still resolves to one of them — and to
        /// the same one every time, since the comparison is a strict improvement over a fixed
        /// iteration order.
        /// </summary>
        public static ZoneCorner HandleAt(Rect rect, Vector2 world, float radius)
        {
            ZoneCorner best = ZoneCorner.None;
            float bestSqr = radius * radius;

            best = Closer(best, ref bestSqr, world, new Vector2(rect.xMin, rect.yMin), ZoneCorner.BottomLeft);
            best = Closer(best, ref bestSqr, world, new Vector2(rect.xMax, rect.yMin), ZoneCorner.BottomRight);
            best = Closer(best, ref bestSqr, world, new Vector2(rect.xMin, rect.yMax), ZoneCorner.TopLeft);
            best = Closer(best, ref bestSqr, world, new Vector2(rect.xMax, rect.yMax), ZoneCorner.TopRight);

            return best;
        }

        static ZoneCorner Closer(ZoneCorner best, ref float bestSqr, Vector2 world,
                                 Vector2 corner, ZoneCorner candidate)
        {
            float dx = corner.x - world.x;
            float dy = corner.y - world.y;
            float sqr = dx * dx + dy * dy;

            if (sqr > bestSqr) return best;

            bestSqr = sqr;
            return candidate;
        }

        /// <summary>
        /// Drags one corner to a new position, pinning the opposite one. Dragged past the far
        /// edge the rect flips rather than inverting, because the result is re-normalised
        /// between the two tiles rather than being computed as a width.
        /// </summary>
        public static Rect Resize(Rect rect, ZoneCorner corner, Vector2 world)
        {
            if (corner == ZoneCorner.None) return rect;

            return Normalise(Opposite(rect, corner), GridCursor.ToTile(world));
        }

        /// <summary>
        /// The tile diagonally opposite a corner. Tile coordinates, not rect edges: a rect of
        /// x 10 width 6 covers tiles 10..15, so its far tile is 15 and not 16.
        /// </summary>
        static Vector2Int Opposite(Rect rect, ZoneCorner corner)
        {
            int minX = Mathf.RoundToInt(rect.xMin);
            int minY = Mathf.RoundToInt(rect.yMin);
            int maxX = Mathf.RoundToInt(rect.xMax) - 1;
            int maxY = Mathf.RoundToInt(rect.yMax) - 1;

            switch (corner)
            {
                case ZoneCorner.BottomLeft:  return new Vector2Int(maxX, maxY);
                case ZoneCorner.BottomRight: return new Vector2Int(minX, maxY);
                case ZoneCorner.TopLeft:     return new Vector2Int(maxX, minY);
                default:                     return new Vector2Int(minX, minY);
            }
        }

        /// <summary>
        /// Moves a rect to a new bottom-left, keeping its size and holding the whole rect
        /// inside the room — a zone half outside the wall is not something the author can
        /// mean.
        /// </summary>
        public static Rect Move(Rect rect, Vector2 bottomLeft)
        {
            int w = Mathf.RoundToInt(rect.width);
            int h = Mathf.RoundToInt(rect.height);

            int x = Mathf.Clamp(Mathf.RoundToInt(bottomLeft.x), 0, TileGrid.Width - w);
            int y = Mathf.Clamp(Mathf.RoundToInt(bottomLeft.y), 0, TileGrid.Height - h);

            return new Rect(x, y, w, h);
        }

        /// <summary>The schema's [x, y, w, h]. Malformed input reads as a 1x1 at the origin.</summary>
        public static Rect RectOf(float[] rect)
            => rect == null || rect.Length < 4
                ? new Rect(0f, 0f, 1f, 1f)
                : new Rect(rect[0], rect[1], rect[2], rect[3]);

        public static float[] ToArray(Rect rect)
            => new[] { rect.xMin, rect.yMin, rect.width, rect.height };
    }
}
```

```csharp
        // -------------------------------------------------------------------- zones

        public LevelZone FindZone(string id)
        {
            if (string.IsNullOrEmpty(id) || Level.zones == null) return null;

            foreach (LevelZone zone in Level.zones)
                if (zone != null && zone.id == id) return zone;

            return null;
        }

        /// <summary>
        /// The zone under a world position, smallest first.
        ///
        /// Smallest wins because zones nest and overlap by design (GDD 6.2 — overlapping air
        /// zones sum). Without this a small vent drawn inside a room-wide thermal would be
        /// permanently unselectable, which is the same reasoning that makes the select tool
        /// test entities before the exit.
        /// </summary>
        public LevelZone ZoneAt(Vector2 world)
        {
            if (Level.zones == null) return null;

            LevelZone best = null;
            float bestArea = float.MaxValue;

            foreach (LevelZone zone in Level.zones)
            {
                if (zone?.rect == null || zone.rect.Length < 4) continue;

                Rect rect = ZoneGeometry.RectOf(zone.rect);
                if (!rect.Contains(world)) continue;

                float area = rect.width * rect.height;
                if (area >= bestArea) continue;

                bestArea = area;
                best = zone;
            }

            return best;
        }

        public LevelZone AddZone(Rect rect, string type = "air")
        {
            var zone = new LevelZone
            {
                id = NextZoneId(),
                type = type,
                rect = ZoneGeometry.ToArray(rect),
                @params = new ZoneParams(),
                start_state = "on",
            };

            var zones = new List<LevelZone>(Level.zones ?? new LevelZone[0]) { zone };
            Level.zones = zones.ToArray();

            SelectedZoneId = zone.id;
            Dirty = true;
            return zone;
        }

        /// <summary>
        /// One setter for both moving and resizing: the geometry has already decided which
        /// of the two a given drag was, and two methods would be the same body twice.
        /// </summary>
        public void SetZoneRect(string id, Rect rect)
        {
            LevelZone zone = FindZone(id);
            if (zone == null) return;

            zone.rect = ZoneGeometry.ToArray(rect);
            Dirty = true;
        }

        public bool DeleteZone(string id)
        {
            LevelZone zone = FindZone(id);
            if (zone == null) return false;

            var zones = new List<LevelZone>(Level.zones);
            zones.Remove(zone);
            Level.zones = zones.ToArray();

            if (SelectedZoneId == id) SelectedZoneId = null;
            Dirty = true;
            return true;
        }

        /// <summary>Lowest unused zNN id, matching how entity ids are allocated.</summary>
        string NextZoneId()
        {
            for (int i = 1; i < 1000; i++)
            {
                string candidate = "z" + i.ToString("00");
                if (FindZone(candidate) == null) return candidate;
            }

            return "z" + Level.zones.Length;
        }
```

```csharp
        /// <summary>Handle hit radius in world units — about 4 px at 20 px/metre.</summary>
        const float ZoneHandleRadius = 0.35f;

        /// <summary>
        /// Every zone in the level, whatever its type.
        ///
        /// Drawn from Session.Level.zones rather than from the world's AirField, because
        /// LevelLoader.LoadZones admits only type "air" — the five inert types never reach
        /// the field, so a view reading it could never show them, and a zone that cannot be
        /// seen cannot be selected or edited. ZoneViewSync still draws the air zones in play;
        /// this is the authoring view.
        /// </summary>
        void DrawZones()
        {
            if (Session.Level.zones == null) return;

            foreach (LevelZone zone in Session.Level.zones)
            {
                if (zone?.rect == null || zone.rect.Length < 4) continue;

                Rect rect = ZoneGeometry.RectOf(zone.rect);
                bool selected = zone.id == Session.SelectedZoneId;
                bool off = zone.start_state == "off";

                // An off zone is dimmed rather than hidden: hiding it would make it
                // impossible to select, and so impossible to switch back on.
                Color fill = ZoneFill(zone.type);
                if (off) fill.a *= 0.4f;

                DrawWorldRect(rect, fill);

                if (!selected) continue;

                Color edge = new Color(1f, 1f, 1f, 0.8f);
                DrawWorldRect(new Rect(rect.xMin, rect.yMax - 0.05f, rect.width, 0.05f), edge);
                DrawWorldRect(new Rect(rect.xMin, rect.yMin, rect.width, 0.05f), edge);
                DrawWorldRect(new Rect(rect.xMin, rect.yMin, 0.05f, rect.height), edge);
                DrawWorldRect(new Rect(rect.xMax - 0.05f, rect.yMin, 0.05f, rect.height), edge);

                DrawHandle(new Vector2(rect.xMin, rect.yMin));
                DrawHandle(new Vector2(rect.xMax, rect.yMin));
                DrawHandle(new Vector2(rect.xMin, rect.yMax));
                DrawHandle(new Vector2(rect.xMax, rect.yMax));
            }
        }

        void DrawHandle(Vector2 corner)
        {
            const float r = ZoneHandleRadius;
            DrawWorldRect(new Rect(corner.x - r * 0.5f, corner.y - r * 0.5f, r, r),
                          new Color(1f, 1f, 1f, 0.9f));
        }

        /// <summary>
        /// Air borrows the fan's blue, so wind looks like wind wherever it comes from. The
        /// inert types get a flat grey: they do nothing, and dressing them in a colour that
        /// suggests they do would be a lie. Never the reserved hazard hue (GDD 13.1).
        /// </summary>
        static Color ZoneFill(string type)
            => type == "air"
                ? new Color(0.45f, 0.65f, 0.75f, 0.30f)
                : new Color(0.55f, 0.55f, 0.60f, 0.22f);
```

```csharp
        /// <summary>
        /// Draw, move, resize and delete zones (level-editor-spec 4, tool 4).
        ///
        /// Mouse-down chooses between three drags: a handle of the selected zone resizes, the
        /// interior of a zone moves it, and empty space creates one. N overrides the middle
        /// case so a zone can be drawn on top of another.
        /// </summary>
        void ZoneTool(Mouse mouse, Vector2 world)
        {
            if (mouse.rightButton.wasPressedThisFrame)
            {
                LevelZone hit = Session.ZoneAt(world);
                if (hit != null)
                {
                    Session.BeginEdit();
                    Session.DeleteZone(hit.id);
                    SyncDynamic();
                    _status = "deleted zone";
                }

                return;
            }

            if (mouse.leftButton.wasPressedThisFrame)
            {
                LevelZone selected = Session.FindZone(Session.SelectedZoneId);

                // Handles belong to the selected zone alone. Every zone showing handles at
                // once is unreadable in a room with several.
                _zoneCorner = selected?.rect != null
                    ? ZoneGeometry.HandleAt(ZoneGeometry.RectOf(selected.rect), world, ZoneHandleRadius)
                    : ZoneCorner.None;

                LevelZone hit = _zoneForceNew ? null : Session.ZoneAt(world);

                if (_zoneCorner != ZoneCorner.None)
                {
                    Session.BeginEdit();
                    _zoneCreating = false;
                    _dragging = true;
                }
                else if (hit != null)
                {
                    Session.SelectedZoneId = hit.id;
                    Rect rect = ZoneGeometry.RectOf(hit.rect);
                    _zoneDragOffset = new Vector2(rect.xMin, rect.yMin) - world;
                    Session.BeginEdit();
                    _zoneCreating = false;
                    _dragging = true;
                }
                else
                {
                    _dragStart = GridCursor.ToTile(world);
                    _zoneCreating = true;
                    _dragging = true;
                }
            }

            if (!_dragging) return;

            if (_zoneCreating)
            {
                if (!mouse.leftButton.wasReleasedThisFrame) return;

                Session.BeginEdit();
                LevelZone created = Session.AddZone(ZoneGeometry.Normalise(_dragStart, GridCursor.ToTile(world)));
                SyncDynamic();

                _dragging = false;
                _zoneCreating = false;
                _zoneForceNew = false;
                _status = $"added {created.id}";
                return;
            }

            LevelZone dragged = Session.FindZone(Session.SelectedZoneId);
            if (dragged?.rect == null) { _dragging = false; return; }

            Rect current = ZoneGeometry.RectOf(dragged.rect);

            Rect updated = _zoneCorner != ZoneCorner.None
                ? ZoneGeometry.Resize(current, _zoneCorner, world)
                : ZoneGeometry.Move(current, world + _zoneDragOffset);

            Session.SetZoneRect(dragged.id, updated);
            SyncDynamic();

            if (mouse.leftButton.wasReleasedThisFrame)
            {
                _status = _zoneCorner != ZoneCorner.None ? "resized zone" : "moved zone";
                _dragging = false;
                _zoneCorner = ZoneCorner.None;
            }
        }
```

Note `Session.BeginEdit()` is called on mouse-**down**, once per stroke, matching `RectTool` and `SelectTool` — never inside the per-frame drag branch, or the undo stack would take a snapshot every frame of the drag.
